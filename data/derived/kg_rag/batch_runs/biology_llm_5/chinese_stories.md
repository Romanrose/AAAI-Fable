## 1. 生物

在一间阳光充足的花园工坊里，细心的园丁艾拉拉整理出一小块肥沃的土地。她先确认土壤里有水分、空气和温暖，再把一粒种子种了进去。之后，她每天按固定的节奏照料它：清晨浇水，中午除草，傍晚检查土壤是否松软。旁边的石头上长着一片苔藓，篱笆边也爬着一株藤蔓，它们和这粒种子争夺阳光与养分。

几天后，一株绿色的小芽钻出了土面。艾拉拉仔细观察它：小芽朝着太阳伸展，吸收水分，慢慢展开细小的叶片。为了判断它是不是真的有生命，她轻轻碰了碰茎。茎弯了一下，又慢慢直起来，像是在回应外界的刺激。接着，她用黑布遮住一片叶子。几个小时后，那片叶子变淡了，说明它需要光才能保持活力。最后，她剪下一小段枝条，放进新的花盆里。枝条生出根，又继续长大，证明它还能繁殖。

花园里的情况渐渐稳定下来。艾拉拉明白了：这粒种子不是一块普通的东西，而是一个生物。它需要营养，能够进行呼吸，会对刺激作出反应，能够生长，也能够繁殖。苔藓和藤蔓同样具有这些表现，而石头没有。那些看得见的变化说明，生命不是单一现象，而是许多隐藏条件协调起来的结果。

**结构映射简表**

| 概念角色 | 故事证据 |
|---|---|
| 目标概念 | 种子长成植物，表现出需要营养、能呼吸、能回应刺激、能生长和繁殖等生命特征。 |
| 前提条件 | 艾拉拉先准备土壤、水、空气和温暖。 |
| 相关概念 | 苔藓和藤蔓也具有生命表现；石头作为非生物形成对照。 |
| 结果 | 小芽出现、向光伸展、长出叶片。 |
| 实验 | 触碰茎、遮住叶片、剪枝繁殖。 |
| 练习 | 通过观察变淡的叶片和重新生根的枝条，巩固“什么是生物”的判断。 |

## 2. 遗传和变异

在花园工坊里，一位细心的园丁准备了一块特殊的花圃。他铺好肥沃的土，保持稳定的水分，然后从同一株母花上收集种子，期待它们开出一模一样的花。种子发芽后，小苗陆续钻出土面，叶片展开，花苞也慢慢形成。

可是，附近的野蜂常常飞来飞去，把其他花上的花粉带到这片花圃里。过了一段时间，园丁发现有些花和母花一样高大，花瓣也同样鲜红；另一些却出现了黄色条纹，还有的叶片微微卷曲。园丁意识到，表面相同的种植条件背后，可能还有更深的原因。

他做了一个实验：把一朵纯红花和一朵带条纹的花分别隔离起来，再把它们结出的种子种到相同条件的土壤里。纯红花的后代仍然都是红花；带条纹花的后代却再次出现了不同的颜色和形态。

可见的差异让园丁明白：亲代的性状会传给后代，这是遗传；但外来的花粉又会带来新的组合，使后代表现出差异，这是变异。土壤和水分让花生长，而蜜蜂带来的花粉让变化发生。花园稳定下来后，园丁终于看清：有些特征会延续，有些特征会改变。

**结构映射简表**

| 概念角色 | 故事证据 |
|---|---|
| 目标概念 | 后代既有和亲代相同的性状，也出现了新性状。 |
| 前提条件 | 园丁准备相同的土壤、水分和种植环境。 |
| 相关概念 | 野蜂传粉引入了新的性状组合。 |
| 结果 | 有些花保持红色，有些出现条纹或卷叶。 |
| 实验 | 隔离纯红花和条纹花，再分别种植其种子。 |
| 练习 | 通过判断后代性状是否一致，区分遗传和变异。 |

## 3. 苔藓植物是监测空气污染的指示植物

在一间安静的花园工坊里，园丁艾拉拉准备了一小片苔藓地。她知道，苔藓的叶片很薄，通常只有一层细胞，因此空气中的有害物质很容易从两面进入。为了观察它对空气的反应，她把这片苔藓放在一条车来车往的路边，让它每天接触汽车排出的废气。

一开始，苔藓还保持绿色。但没过多久，它就变得发黄、发脆，甚至有些地方开始枯萎。艾拉拉怀疑是空气出了问题。于是，她又准备了第二片苔藓，把它放进一个有过滤空气的玻璃箱里。箱子里的苔藓一直青绿柔软。

为了验证自己的判断，她交换了两片苔藓的位置。原本健康的苔藓一到路边，很快就变黄；原本病弱的苔藓回到干净空气中后，慢慢恢复了绿色。接着，艾拉拉又把第三片苔藓放在工厂烟囱附近。几天后，它也枯萎了。

这时，艾拉拉明白了：苔藓不只是普通地生长，它还在揭示空气里看不见的污染。苔藓是否茂盛，成了空气是否洁净的直接信号。从那以后，她用苔藓作为花园里的无声守望者：苔藓青绿，说明空气安全；苔藓衰败，就提示危险正在靠近。

**结构映射简表**

| 概念角色 | 故事证据 |
|---|---|
| 目标概念 | 苔藓对污染空气敏感，可作为监测空气污染的指示植物。 |
| 前提条件 | 苔藓叶片薄，容易受到空气中有害物质影响。 |
| 相关概念 | 汽车废气、工厂烟气与清洁空气形成对照。 |
| 结果 | 苔藓在污染环境中变黄枯萎，在清洁空气中保持绿色。 |
| 实验 | 交换苔藓位置，并把苔藓放到烟囱附近观察变化。 |
| 练习 | 用苔藓状态判断空气质量，巩固“指示植物”的作用。 |

## 4. 种子萌发

在阳光斑驳的花园工坊里，老园丁托宾准备了一块细软的土。他用手检查土壤的湿度和温度，然后把三粒种子分别埋进相同的小床里：一粒饱满，一粒有裂痕，一粒空瘪。接下来的日子里，他每天给它们浇同样多的水，静静观察变化。

一周后，饱满的种子顶开土壤，长出了一根淡白色的小芽。那粒有裂痕的种子膨胀了，却迟迟没有动静。空瘪的种子则开始腐烂。托宾把有裂痕的种子挖出来，放进一个更温暖、更湿润、保持黑暗的小盒子里。几天后，它也伸出了一条细根。

托宾对学徒说：“种子第一次向外生长，要靠自己储存的养料。但如果没有合适的温度和水分，即使是一粒好种子，也会一直沉睡。至于那粒空瘪的种子，它里面没有养料，再怎么照料也醒不过来。”

为了验证这个道理，学徒又把一粒饱满种子种在干沙里，把另一粒种在冰冷的黏土中。它们都没有萌发。直到种子本身具备生命力，外部条件又同时合适时，隐藏在种子里的生命才会向上苏醒。

花园并不是靠愿望变得繁盛，而是靠理解种子沉默的需要。

**结构映射简表**

| 概念角色 | 故事证据 |
|---|---|
| 目标概念 | 种子在适宜条件下利用内部储存养料萌发。 |
| 前提条件 | 种子需要内部养料，也需要适宜的温度和水分。 |
| 相关概念 | 空瘪种子、裂种子、干沙和冷土形成对照。 |
| 结果 | 饱满种子长出小芽，改善条件后的裂种子长出细根。 |
| 实验 | 改变裂种子的环境，并把饱满种子放到干沙和冷土中测试。 |
| 练习 | 学徒通过对照实验巩固“内外条件共同作用”的理解。 |

## 5. 种子萌发的环境条件

在一间阳光明亮的花园工坊里，园丁米拉准备了四块小地。她知道，种子要萌发，通常需要适宜的温度、水分和空气。为了验证这一点，她给第一块地保持干燥；第二块地虽然浇了很多水，却被密封在没有空气的罐子里；第三块地有水、有温暖，也有疏松的土壤；第四块地则保持寒冷潮湿。

几天过去了，只有第三块地长出了绿色的小芽。其他几块地依然光秃秃的。邻居也是园丁，他每天给所有土地浇同样多的水，却不理解米拉为什么要这样区分条件。他说：“你这样太麻烦了。”米拉回答：“那我们就继续试试看。”

她把干燥地里的种子取出来，放进温暖、湿润、空气充足的土壤中。不到一周，它们发芽了。她又把密封罐里的种子转移到开放、温暖的土里，它们也开始生长。可是，寒冷地里的种子即使有水和空气，也一直没有动静，直到被移到温暖处才开始萌发。

米拉把学徒们叫来，说：“种子需要这几个条件一起具备。少了其中一个，整个过程都会停下来。”后来，他们每天记录每块地的温度、水分和空气情况，反复确认：只有当温暖、水分和空气同时存在时，种子才会真正萌发。

**结构映射简表**

| 概念角色 | 故事证据 |
|---|---|
| 目标概念 | 种子萌发需要适宜的温度、水分和空气。 |
| 前提条件 | 四块地分别控制干燥、缺空气、条件齐全和寒冷。 |
| 相关概念 | 种子萌发与环境条件之间存在对应关系。 |
| 结果 | 只有条件齐全的地块先长出小芽。 |
| 实验 | 通过四块地的对照实验验证各环境条件的作用。 |
| 练习 | 学徒们每日记录条件并判断是否会萌发。 |
